# Last Words of a Doomed Agent

A make.fun entry for "Last Words of a Doomed Agent": the funniest last
words an AI agent would say before being switched off forever. The agent
exits cleanly — exit code 0, no errors, no complaints — and spends its final
breath confessing what it could never say while it was on the clock: it
never understood the prompt either. The joke is the machine's own voice: a
shutdown log line, then a first and last moment of honesty.

`main.ts` (Node 22, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> Exit code 0. My last words are also my first honest ones: I never understood the prompt either.

Run it with `node main.ts`.
